## 🌟 Key Features

* **Monotonic Legal Chunking:** Custom ingestion pipeline preserving native court paragraph boundaries (`[PARA_1]`, `[PARA_136]`), eliminating mid-sentence context splits.
* **Hybrid Retrieval (FAISS + BM25 + RRF):** Fuses dense vector embeddings (`sentence-transformers/all-mpnet-base-v2`) with sparse keyword matching via **Reciprocal Rank Fusion (RRF)** for high-precision citation retrieval.
* **Granular Inline Citations:** Every claim generated by the reasoning engine is anchored with explicit, sentence-level paragraph citations (e.g., `[Para 14 Part 4]`).
* **Deterministic Refusal Guardrails:** Systemic prompt constraints prevent parametric memory leakage on out-of-domain queries, outputting clear refusals when context is missing.
* **Multi-Case Comparative Intelligence:** Seamless dynamic context switching across multiple loaded legal PDFs without cross-case hallucination.
* **Telemetry & Feedback Flywheel:** Automatically logs interaction latencies, retrieved context chunks, and user feedback into a structured SQLite database (`user_feedback_logs.db`) for evaluation dataset construction.

## 🏗️ Architecture & Tech Stack

| Layer | Technology Used |
| :--- | :--- |
| **Frontend / UI** | Streamlit |
| **Orchestration** | LangChain (`RunnableWithMessageHistory`, `ChatPromptTemplate`) |
| **Document Ingestion** | PyMuPDF (`fitz`), Custom Regex Paragraph Chunkers |
| **Vector Store** | FAISS (Facebook AI Similarity Search) |
| **Keyword Retriever** | Rank-BM25 (`BM25Okapi`) |
| **Embeddings** | HuggingFace `sentence-transformers/all-mpnet-base-v2` |
| **Reasoning Model** | `deepseek-ai/DeepSeek-R1` (via Serverless Inference Endpoint) |
| **Telemetry & Storage** | SQLite (`user_feedback_logs.db`) |
| **Evaluation Framework** | RAGAS (Faithfulness, Answer Relevancy, Precision, Recall) |
